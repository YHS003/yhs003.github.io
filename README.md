# 👨‍💻 Yehya Hamdy Shehata — Personal Portfolio

A professional personal portfolio website showcasing my technical skills, projects, achievements, and experience across multiple areas of technology and engineering.

Built from scratch using **HTML, CSS, and JavaScript**, with a focus on responsive design, clean structure, practical interactions, and a consistent visual identity.

## 🌐 Live Demo

[View Portfolio](https://yhs003.github.io/portfolio/)

I am a **Computer & Control Engineering graduate** with a broad interest in technology, software, cybersecurity, IT administration, and embedded systems.

My technical journey spans several areas:
